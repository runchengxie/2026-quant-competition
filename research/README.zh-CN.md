# 离线研究

[English](README.md)

- [加密做市](crypto-mm/README.zh-CN.md)：事件驱动的可见队列模拟，使用合成 Parquet 演示数据。
- [股票实验室](equity-lab/README.zh-CN.md)：基于每日 CSV/YAML 的分数权重回测，使用虚构港股代码演示数据。

两个目录都是独立的 Python 3.12 项目，各有 `uv.lock`、测试和 MIT 许可证，应进入对应目录安装并运行检查。根项目执行依赖和测试保持独立，根目录 Ruff 仍检查新增文件。英文文档为事实依据，并提供 zh-CN 阅读文档，没有引入运行时国际化系统。

生成的数据和报告放在配置的外部 `DATA_ROOT/2026-quant-competition/research/` 下。两个包均不连接券商，产物不是可执行的目标交接文件。已发布 v1 JSON schema 接受 JP/US，运行时市场规范化还识别 HK，两者存在尚未解决的不一致，加密市场不受支持。比赛资格及真实市场适用性需要单独核实，解读前请查看各包限制。

MIT 仅用于新增子项目代码，不改变根目录已有代码或第三方依赖的许可状态。
