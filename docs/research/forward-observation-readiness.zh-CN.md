# 前瞻观察准备

尚未启动前瞻观察。已发布实验复用了已查看的历史数据和当前固定标的池，未计分尾段也不是未见测试集。

候选方向包括美股每周调仓的 `sma_cross`、港股每月调仓的 `momentum_20d`，以及加密 `trend_200d` 风险控制。候选仅表示研究问题，不代表获批、最优策略或所有规则都改善了结果。60% 仓位对照仍是事后诊断，应结合[策略指南](strategies.zh-CN.md#formal-ablation)查看全部费用和窗口。

收集真正的新证据前，需要完成以下准备。

1. 固定新鲜不可变数据的身份和观察截止点。当前股票数据止于 2026-10-20，选中加密切片止于 2026-09-30。
2. 在观察结果前定义标的池及成员日期。当前美股、港股各十只股票及八个加密产品，不等于历史标普 500 或全市场成员。
3. 固定公司行动、分红、可成交价格、费用、交易单位和容量假设。当前前收盘信号与收盘到收盘收益代理不足以验证执行。
4. 在新观察前声明准确决策日历、策略与参数集、评估指标、停止条件和缺失数据处理方式，保留不理想结果及证据来源。
5. 单独确认比赛、账户、场所与产品资格。研究 artifact 不是可执行目标交接。
6. 新采集器、Paper 登录、计划任务或下单接线分别授权。本次回溯 CLI 和网页均不会启用这些功能。

未来报告应区分协议冻结时间、数据可用时间和实际执行时间。除非另行实现有版本标识的连续账户协议，否则继续保留独立现金起点。当前公开内容仅是窗口汇总对比，不会据此开始记录实时业绩。
