# 选股、费用与执行延迟

[English](strategy-comparison.md)

这组美股日内选股在单边20/40 bps成本下，已完成的估算都亏损。按原定时间执行时，Ridge在两段可比窗口中都低于简单反转。加密周频趋势对执行时间敏感，和同目标仓位对照相比也没有稳定优势。本轮使用已研究过的历史，结果属于历史重检。

本轮记录了42次模型拟合、72个股票比较单元和288个加密比较单元。股票有45项完成、27项无法比较，加密288项均完成。缺失结果和恒定预测都保留在记录中。看过结果后没有追加拟合或账户回放。72项股票比较共用三段窗口，288项加密比较共用十二段窗口，不能当作独立市场样本数。

## 美股选股与成本估算

冻结日线输入有658,472个标的日，覆盖2025-09-25至2026-10-20。每个月使用此前20个完整XNYS交易日选候选，前一收盘价至少为5 USD，日均成交金额至少为1,000万USD，最多保留500个来源候选。历史身份、证券类型和来源选择仍有缺口。这份股票池尚未认证为历史普通股池或标普500成分股。

等权使用信号日有可用OHLC的全部月度候选，月份归属按信号日期确定。简单反转、Ridge和Elastic Net各选分数最高的50个，同分时按候选标识排序。全部预测值相同时，这项排序记为不可用。持仓集中程度不同，收益差也包含这部分风险差异。

简单反转把信号日第一笔到最后一笔的价格收益取负，跌得越多，排名越靠前。学习模型预测下一个交易日的日内价格收益。IC衡量分数和后续收益的排序是否同向，同分使用平均名次。MSE衡量收益预测值与实际值的平方误差。两项指标先逐日计算，再给每个有效日期相同权重。

Ridge和Elastic Net沿用[预测协议](equity-predictive.zh-CN.md)中的六个特征和参数网格。三个窗口各请求20个信号日期，训练至少有126个更早的交易日标签。此前日期的最后20%用于内部验证。训练标签必须在下一决策边界之前结束，填补缺失值和缩放也只使用训练数据。本轮进行了36次验证拟合和6次选定参数后的重拟合，使用一个工作进程、最多两个原生线程，工作进程限时1,200秒。

| 信号日期 | 原定执行时间 | 延迟执行 |
| --- | --- | --- |
| 2026-07-27至2026-08-21 | 下一个确切XNYS交易日 | 再晚一个XNYS交易日 |
| 2026-08-24至2026-09-21 | 下一个确切XNYS交易日 | 再晚一个XNYS交易日 |
| 2026-09-22至2026-10-19 | 下一个确切XNYS交易日 | 再晚一个XNYS交易日 |

价格代理使用执行日第一笔可用的常规时段成交价买入，以最后一笔卖出，之后回到现金。每个窗口的初始净值记为1，以USD计价。仓位可分割，只做多。正式竞价、整手、最低佣金、价差深度和实际成交能力仍未验收。

设单边费率为`f`，选中组合的日内价格收益为`r`，当天净值倍数为`(1+r)*(1-f)/(1+f)`。买入费先从可用现金支付，卖出费按卖出金额计算。单边费率为0/20/40 bps，每天买卖两个方向都会计费。零费用用于对照。扣费会改变后续可投入资金，因此累计扣费数与零费用收益差可能不同。

模型会先保存全部月度候选行的分数，再按可用的未来标签计算IC和MSE。组合还要求信号日价格可用，并在查看结果之前确定持仓。选中标的缺少执行日结果时，该账户保留为不可比较，其余标的不会重新分摊仓位。后面的日期不能填补这个缺口，整个窗口的连续收益仍不可用。最后一个延迟窗口也超出了保留的执行交易日历。

| 单边成本 | 执行时间 | Ridge高于等权 | 配对收益差中位数 |
| --- | --- | --- | --- |
| 20 bps | 原定时间 | 2个可比窗口中有2个，请求3个 | +4.3621个百分点 |
| 40 bps | 原定时间 | 2个可比窗口中有2个，请求3个 | +4.0267个百分点 |
| 20 bps | 晚一个交易日 | 2个可比窗口中有0个，请求3个 | −3.8199个百分点 |
| 40 bps | 晚一个交易日 | 2个可比窗口中有0个，请求3个 | −3.5262个百分点 |

相对等权的改善没有带来正收益。在已测试的非零成本下，30项已完成估算都亏损，亏损最少的一项为−3.4168%。按原定时间执行时，简单反转在两段可比窗口、两档成本下都高于Ridge。Elastic Net在第一段输出恒定预测。最后一段的部分选中结果缺失，也使等权和学习模型无法给出完整收益。有些比较单元同时包含多种原因，原因次数不能相加当作账户数。

## 加密持币与趋势对照

沿用固定的八种现货币和12个独立窗口。每个窗口有252天准备期和90天评分期，初始净值单独记为1，以USDT计价。窗口之间不拼接，USDT也没有换算成USD。

| 方法 | 规则 |
| --- | --- |
| `buy_hold_equal_weight` | 开始时等权买入一次，之后保留实际数量和现金 |
| `fixed60_weekly` | 八种币等分60%的目标总仓位 |
| `trend_weekly` | 现有严格200日趋势规则，波动目标40% |
| `matched_weekly` | 在调仓时等分趋势策略的目标总仓位 |

后三种方法在开始时建仓，之后按UTC周一的决策日期调仓，其余日期持有实际数量。延迟一天会同时后移目标和调仓日期，首次延迟成交前保持现金。0/35/50 bps是单边总成本假设，每个扣费账户和零费用账户都使用现有现金账本重算。期末持仓按价格计值，不另做终止卖出。本轮在600秒工作进程限时内保留了288个扣费账户和288个零费用账户。

趋势规则选出价格高于过去200日均值的币，再在这些币之间等分仓位。近期组合波动决定目标总仓位，年化波动目标为40%，不加杠杆。严格规则在估计波动为零时持有现金，实际波动仍可能偏离目标。

| 单边成本 | 执行时间 | 趋势高于持币 | 配对收益差中位数 |
| --- | --- | --- | --- |
| 35 bps | 原定时间 | 8/12 | +5.4464个百分点 |
| 50 bps | 原定时间 | 8/12 | +5.1839个百分点 |
| 35 bps | 晚一个UTC日 | 6/12 | +1.3345个百分点 |
| 50 bps | 晚一个UTC日 | 7/12 | +1.2912个百分点 |

持币和固定60%仓位的风险与趋势策略不同。周频匹配对照在调仓时匹配目标总仓位，实际权重和风险仍会漂移。原定时间下，趋势在两档非零成本中都只在5/12个窗口高于这项对照，收益差中位数分别为−0.3830和−0.4750个百分点。两边都延迟后，变为6/12，中位数为+0.3809和+0.2846个百分点。这些描述性结果尚未证明稳定的选币优势或统计显著性。日线数据也没有提供做市成交和实际容量证据。

## 收益集中度与输入质量

网页展示最大标的占正价格贡献的比例，分母只包含正贡献。没有正贡献时，占比保持不可用。另一项诊断把净收益最高的五天改为持有现金，再重算复利。这五天是看过结果后挑出的，无法直接用作选时规则。

日线检查没有发现重复标的日、非交易日记录、非有限数值或负成交金额。441行没有可用OHLC，其中包含缺失价格，共有2,205个数值缺失。657,731个标的日的身份尚未核实。完整的历史类型、公司行动和特征可用时间证据，仍是正式交易业绩的验收条件。

分钟检查读取一个固定的通用分区行组，共120,017行、127个代码。所选列读取了约1.09 MB压缩数据，其中49,530行为常规交易时段。没有发现重复分钟键、有成交时的OHLC异常或常规时段日期错位。全部样本中有66,650行零成交量、62行缺少报价、37,771行价差超过中间价的5%。样本包含盘前盘后，不能据此估计全市场质量或认证整个转换结果。

本次存储检查时，原始日分区转换和标准按证券Zstd6版本都报告完成629,687,711行，新的delta/Zstd12重压缩仍在运行。本轮没有搬迁数据或改动数据入口。存储交接还需要所属任务的完整凭证验收，这次小样本检查没有替代该步骤。

## 命令与产物

使用Python3.12和现有锁定环境，股票CLI需要可选的`predictive` profile。两个真实数据CLI都要求带匹配锁文件的源码和已批准的所属项目单次预算。本轮预算已经使用，改输出位置或代码不会获得另一次运行机会。

```sh
python -m equity_lab.predictive.comparison_cli --help
python -m crypto_mm.daily.comparison_cli --help
python -m competition_tools.evaluation.run_record --run-root /absolute/completed-bundle
python -m competition_tools.evaluation.comparison_evidence --run-root /absolute/completed-bundle --output /absolute/new-public-candidate.json
```

研究包命令分别使用各自环境，根命令使用根环境。将占位路径换成绝对路径，Windows需要盘符。最后一条命令只投影已保存的结果，不拟合模型或回放账户，并拒绝覆盖已有输出。它需要完整运行目录，包括保留的`source/`和输入。运行后补充不可比较原因没有改变科学数值，也没有增加拟合或回放。
