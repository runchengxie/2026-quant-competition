# 策略对照实验

[English](strategy-controls.md)

420 项历史对照实验已经完成，可以比较固定规则在指定费用下的表现。真实的后续观察仍为零，这些结果尚不能证明策略在新到数据上的表现。

实验于 2026-10-23 通过产物及计算复核。项目所有者已确认取得本批结果的展示授权。网页现公开 420 项汇总结果及 224 组配对比较，同时显示完成数量和证据缺口。

## 比较了什么

美股沿用固定的 10 只现时股票和单独的 SPY 输入，以美元计价，覆盖 2023-01-03 至 2026-10-20，共 953 个交易日。加密使用固定的 8 个现货币种，以 USDT 计价，完整共同区间为 2023-01-01 至 2026-09-30，共 1369 天。数据来自当前固定池，历史标普 500 和全市场成分仍待补齐。本次没有向服务商请求新数据。

两个市场都预热 252 行。美股有 11 个完整的 63 日窗口，费用为 20/40 bps。加密有 12 个完整的 90 日窗口，费用为 0/10/25 bps。网格共美股 132 项、加密 288 项任务，所有请求任务都保留在分母中。

美股比较每日及每月等权、正收益过滤的近 20 个交易日动量，并分别加入每月调仓缓冲。目标权重与持仓漂移后权重的绝对差值之和达到 0.20 才交易，现金也计入比较。初次建仓允许交易，等于阈值时交易，并使用 1e-12 的绝对容差处理浮点相等。跳过检查点时持有原股份。选择为空时在计划检查点退出，不增加每日退出规则。

加密保留四条旧规则，新增严格的趋势波动率投入控制、60% 投入的等权组合、严格波动率等权组合，以及在同一滞后决策时点跟随严格趋势方案投入比例的等权组合。严格规则使用当前所选组合最近 20 个已完成简单收益率的样本标准差，目标年化波动率为 40%，杠杆上限为 1。测得零波动时持有现金，历史不足或含非有限值时阻塞计算。原等权基线仍是买入后持有，旧零波动处理和事后 60% 标签保持原状。

相同投入比例下，两条规则的实际风险仍可能不同，应同时看波动、回撤和换手。每个窗口独立从净值 1 开始，结束时不强制平仓。美股是复权价格核算，不含分红总回报。USDT 未换算成美元。不能把窗口拼成连续曲线，也不能称作未观察过的样本外证据。

## 核验与发布

历史协议在 UTC 2026-10-23 10:39:17 固定，晚于六个后续候选的 10:37:23 固定时间，早于计算。科学源码为 `eb3c146911d5708ca02682efa77795f0a077952c`，计划 SHA-256 为 `c43419690ea26be3e5217d5aaa7dcf3558dd54448152d47f2a2216d0330ff87c`。

计算累计使用 205.797 秒，未超过同一个 3600 秒预算。另用 NumPy 从归一化源收盘价重算了 10 组首尾窗口等权账本，覆盖持仓、费用、现金和全部汇总指标，并核对全部 224 组配对身份、日期、费用及差值。这是账本抽算，没有另行独立重写全部策略规则。逐期产物、比较表、源码快照和私有报告保留在外部数据目录。

Pages 只接收 `competition.public_strategy_controls.v1`。当前为 `measured`，计划和完成数均为 420，阻塞数为零，包含420 项汇总结果和224 组配对。这里的 `measured` 指历史实验已测得结果，不代表可执行交易或已开始真实观察。授权绑定本批计划和结果，未来批次仍需各自的审阅记录。调用者设置布尔标志不能建立发布权限。包含数字的导出须有绑定具体计划及结果的权限审阅摘要，Pages 检查还要求具体公开快照的摘要经过审阅。原有公开快照保留原规则、身份和范围。

## 命令与契约

使用已配置的外部环境。下方 `/absolute/...` 是占位路径，Windows 须换成带盘符的绝对路径。配置、输入、保留源码和输出都放在源码目录外。

```sh
python -m competition_tools.team controls --help
python -m competition_tools.team controls --config /absolute/team.toml --spec /absolute/controls-spec.json --output-root /absolute/new-study
python -m competition_tools.check_controls_delivery --config /absolute/team.toml --output-root /absolute/new-synthetic-check
python -m competition_tools.check_controls_reference --plan /absolute/study/plan.json --results /absolute/study/run/results.json --output-root /absolute/new-reference
```

参考计算命令需要已有的日线数据环境，包括 NumPy。`competition.strategy_controls_spec.v1` 绑定两个 manifest、预期摘要、固定的六条和八条规则、费用及预算。独立研究包通过新的版本化 job、batch、result 和 period 契约交换产物，不导入根项目包。原 v1/v2 研究任务、v3 对照规格和旧 catalog 摘要均保持原状。

预算上限为 512 项、每批 384 项、累计 3600 秒，核验与允许的检查点恢复都计入时间。CLI 创建新研究，`run_controls` API 使用原冻结计划检查恢复条件。预算不明或检查点变化时阻塞恢复，已经尝试失败的任务不会获得新预算重试。

美股基准对照单独保存在私有补充产物中，按冻结的 job ID 关联。每个窗口提供 SPY 价格收益、按相同费用计算的买入持有净收益，以及策略相对两者的超额收益。基准包含初次建仓费，不做期末卖出，使用最后一个预热日的收盘价建仓，与首个计分收益区间一致。拆股调整价格不包含股息总回报。补充计算不重跑策略、不修改冻结产物，仍受同一公开发布门槛约束。
