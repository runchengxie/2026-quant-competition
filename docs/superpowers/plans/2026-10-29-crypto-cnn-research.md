# Crypto CNN research publication implementation plan

**Goal:** Publish the explored low-turnover CNN comparison with clear assumptions and bilingual navigation.

**Architecture:** Add one Astro research page, a curated aggregate JSON and controls that progressively enhance a complete static result table. Keep original source data and execution systems separate.

**Tech Stack:** Astro, static JSON, native SVG, JavaScript, Playwright.

- [ ] Add a curated aggregate of the tested scenarios and a bilingual research page.
- [ ] Check input and disclosure accuracy, desktop/mobile, light/dark, content allowlist and CI.
