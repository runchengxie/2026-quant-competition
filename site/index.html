PROJECT

Separate research from execution

The research system produces versioned target portfolios and lineage records. The execution system validates targets, calculates rebalance differences, and supports controlled testing through IB Gateway Paper. Manual review and dry-run remain the default safeguards.

Strategy candidates

The team is comparing Hong Kong Point-in-Time equity selection with a U.S. ETF portfolio using AIVIX signals. No competition strategy has been selected or registered.

Data and calculation

The project is evaluating how AIVIX alternative data and Index One index calculation may work together. Entitlements, timestamps, weight reconciliation, and contribution still require validation.

Paper execution

Execution adapters convert target portfolios into order intents and preserve audit and reconciliation boundaries. This site does not show live account or trading information.
